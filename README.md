# JoyTrack Interactive Prototype

Interactive school records, attendance, and timetabling prototype for Joyland Academy.

## Live demo

[Open the JoyTrack prototype](https://mysterioukay.github.io/joytrack-interactive-prototype/)

## Source code

[View this GitHub repository](https://github.com/mysteriouKay/joytrack-interactive-prototype)

This is a static, clickable UI prototype. Navigation and form responses are simulated; the prototype does not save records to a backend or database. The site is published from the `master` branch using GitHub Pages.
